QR & ลิงก์

สร้าง QR Code

เปิดเครื่องมือ →

แปลงลิงก์หรือข้อความให้เป็น QR Code ปรับแต่งสี รูปแบบจุด และใส่โลโก้ตรงกลางได้

  1. กรอก ลิงก์ปลายทาง หรือข้อความที่ต้องการในช่องอินพุต — QR จะแสดงตัวอย่างขึ้นมาทันที
  2. ปรับแต่งได้: สีจุด/พื้นหลัง, รูปแบบจุด (ค่าเริ่มต้นคือ "เหลี่ยม"), และ ขนาด
  3. ต้องการโลโก้ตรงกลาง ให้กดอัปโหลดรูปโลโก้ (ปรับขนาดได้)
  4. กด ดาวน์โหลด PNG หรือ SVG เพื่อบันทึกไฟล์
ไฟล์และข้อมูลทั้งหมดสร้างในเครื่องคุณ ไม่ถูกส่งขึ้นเซิร์ฟเวอร์

QR สำเร็จรูป

เปิดเครื่องมือ →

สร้าง QR สำหรับงานเฉพาะทาง สแกนแล้วทำงานได้เลย

WiFiนามบัตร vCardอีเมลSMSโทร
  1. เลือก แท็บชนิด ที่ต้องการด้านบน
  2. กรอกข้อมูลของชนิดนั้น เช่น WiFi = ชื่อเครือข่าย + รหัสผ่าน · vCard = ชื่อ/เบอร์/อีเมล/บริษัท
  3. QR แสดงสดทันที ปรับสี/ขนาดได้เหมือนหน้าสร้าง QR
  4. กดดาวน์โหลด PNG/SVG
ตัวอย่าง: QR แบบ WiFi สแกนด้วยมือถือแล้วเชื่อมต่อเน็ตได้เลยโดยไม่ต้องพิมพ์รหัส

QR พร้อมเพย์

เปิดเครื่องมือ →

สร้าง QR รับเงิน/โอนเงินพร้อมเพย์ จากเบอร์โทรหรือเลขบัตรประชาชน

  1. เลือกว่าจะใช้ เบอร์โทรศัพท์ หรือ เลขบัตรประชาชน 13 หลัก
  2. กรอกเลขให้ถูกต้อง (ระบบตรวจรูปแบบให้)
  3. ใส่ จำนวนเงิน ถ้าต้องการระบุยอด หรือเว้นว่างเพื่อให้ผู้โอนกรอกเอง
  4. ดาวน์โหลด/บันทึก QR ไปใช้ติดหน้าร้านหรือส่งให้ผู้โอน
ก่อนใช้รับเงินจริง ควรลองสแกนด้วยแอปธนาคารจริงสัก 1 ครั้ง ให้แน่ใจว่าขึ้นชื่อบัญชี/ยอดถูกต้อง
รูปภาพ & PDF

ลดขนาด / แปลงรูปภาพ

เปิดเครื่องมือ →

ย่อขนาด บีบอัด และแปลงฟอร์แมตรูปภาพหลายไฟล์พร้อมกัน

  1. ลากรูปมาวาง หรือคลิกเลือกไฟล์ (เลือกได้หลายไฟล์)
  2. ตั้งค่า: ขนาดสูงสุด (px) หรือ เปอร์เซ็นต์, คุณภาพ (สำหรับ JPG/WebP), และ ฟอร์แมตออก (JPG/PNG/WebP)
  3. กด ประมวลผลทั้งหมด — ระบบจะแสดงขนาดก่อน/หลัง
  4. ดาวน์โหลดทีละไฟล์ หรือกด "ดาวน์โหลดทั้งหมด" เพื่อได้เป็นไฟล์ ZIP
รูปถูกประมวลผลในเบราว์เซอร์ ไม่ถูกอัปโหลดขึ้นเซิร์ฟเวอร์

รูป→PDF / รวม / แยกหน้า / ดึงหน้า

เปิดเครื่องมือ →

จัดการ PDF 4 โหมด เลือกจากแท็บด้านบน

  1. รูป→PDF: เลือกรูปหลายไฟล์ เรียงลำดับด้วยปุ่มลูกศร เลือกขนาดหน้า (A4 หรือพอดีรูป) แล้วรวมเป็น PDF
  2. รวม PDF: เลือกไฟล์ PDF หลายไฟล์ จัดลำดับ แล้วรวมเป็นไฟล์เดียว
  3. แยกหน้า: เลือก PDF 1 ไฟล์ → เว้นว่าง (=ทุกหน้า) หรือระบุช่วง เช่น 1-3,5 → ได้ PDF แยกไฟล์ละหน้า รวมเป็น ZIP
  4. ดึงหน้า: เลือก PDF → ระบุหน้าที่ต้องการ → รวมเฉพาะหน้าเหล่านั้นเป็น PDF ไฟล์เดียว
ยังไม่รองรับ: บีบอัดขนาด PDF และแปลง PDF → Word
เครื่องคำนวณ

คำนวณผ่อน / สินเชื่อ

เปิดเครื่องมือ →

คำนวณค่างวดรายเดือน ดอกเบี้ยรวม และตารางผ่อนชำระ

  1. กรอก เงินต้น, ดอกเบี้ย % ต่อปี และ จำนวนงวด (เดือน)
  2. เลือกแบบดอกเบี้ย: ลดต้นลดดอก (สินเชื่อบ้าน/รถทั่วไป) หรือ คงที่ (Flat)
  3. ดูผลทันที: ค่างวด/เดือน, ดอกเบี้ยรวม, ยอดชำระรวม และ ตารางผ่อนต่องวด

ชุดเครื่องคำนวณ

เปิดเครื่องมือ →

เครื่องคำนวณที่ใช้บ่อย 5 อย่างในที่เดียว เลือกจากแท็บ

BMIส่วนลดVAT 7%เปอร์เซ็นต์ทิป
  1. BMI: กรอกน้ำหนัก + ส่วนสูง → ได้ค่า BMI + เกณฑ์แปลผล (ตามเกณฑ์คนเอเชีย)
  2. ส่วนลด: ราคาเต็ม + % ลด → ราคาสุทธิ + ยอดที่ประหยัด
  3. VAT 7%: บวก VAT เข้าราคา หรือถอด VAT ออกจากยอดรวม
  4. เปอร์เซ็นต์: คำนวณ % 3 แบบ (X เป็นกี่% ของ Y / เพิ่ม-ลดกี่% / หาจำนวนเต็ม)
  5. ทิป: ยอดบิล + % ทิป + หารกี่คน → ทิป, ยอดรวม, ต่อคน

แปลงหน่วย / อุณหภูมิ / สกุลเงิน

เปิดเครื่องมือ →

แปลงหน่วยหลายหมวด + อัตราแลกเปลี่ยนสกุลเงินล่าสุด

  1. เลือก หมวด (ความยาว/น้ำหนัก/พื้นที่/ปริมาตร/ความเร็ว/ข้อมูล/เวลา/อุณหภูมิ/สกุลเงิน)
  2. เลือกหน่วย จาก และ เป็น แล้วพิมพ์ตัวเลข — แปลงสดทันที (พิมพ์ฝั่งไหนก็ได้)
  3. หมวดพื้นที่มีหน่วยไทย (ไร่/งาน/ตารางวา) ให้ด้วย
สกุลเงินดึงอัตราล่าสุดจากอินเทอร์เน็ต (frankfurter.dev) — ต้องต่อเน็ต ใช้เพื่ออ้างอิงเท่านั้น ไม่ใช่เรตซื้อขายจริง

อ่านจำนวนเงินเป็นตัวอักษรไทย (บาทถ้วน)

เปิดเครื่องมือ →

แปลงตัวเลขจำนวนเงินเป็นคำอ่านภาษาไทย สำหรับใบเสร็จ/เช็ค/ใบกำกับภาษี

  1. พิมพ์ จำนวนเงิน (ใส่ทศนิยม 2 ตำแหน่งเป็นสตางค์ได้ เช่น 1250.50)
  2. คำอ่านภาษาไทยแสดงทันที เช่น "หนึ่งพันสองร้อยห้าสิบบาทห้าสิบสตางค์"
  3. กดปุ่ม คัดลอก เพื่อนำไปวางในเอกสาร

คำนวณภาษีเงินได้บุคคลธรรมดา

เปิดเครื่องมือ →

ประมาณภาษีที่ต้องจ่ายจากเงินได้และค่าลดหย่อน แบบขั้นบันได

  1. กรอก เงินได้ทั้งปี
  2. กรอก ค่าลดหย่อน ที่มี (คู่สมรส/บุตร/บิดามารดา/ประกันสังคม/ประกันชีวิต-สุขภาพ/RMF-SSF/ดอกเบี้ยบ้าน/บริจาค) — ระบบจำกัดเพดานให้อัตโนมัติ
  3. ดูผล: เงินได้สุทธิ, ภาษีที่ต้องชำระ, อัตราภาษีเฉลี่ย และตารางแยกตามขั้น
เป็นการประมาณการเบื้องต้น กฎ/เพดานลดหย่อนเปลี่ยนได้ในแต่ละปี — ตรวจสอบกับกรมสรรพากรก่อนยื่นจริง
ตัวช่วย & สุ่ม

สุ่มรายชื่อ / วงล้อสุ่ม / สุ่มเลข / ลูกเต๋า

เปิดเครื่องมือ →

สุ่มอย่างเป็นธรรมด้วยตัวสุ่มเข้ารหัส (crypto)

  1. สุ่มรายชื่อ: วางรายชื่อทีละบรรทัด → เลือกจำนวนที่จะสุ่ม + ให้ซ้ำได้/ไม่ได้
  2. วงล้อสุ่ม: ใส่รายการ → กดหมุน → ได้ผู้ชนะ
  3. สุ่มเลข: ระบุช่วง min–max + จำนวน + ไม่ซ้ำ
  4. ลูกเต๋า / เหรียญ: ทอยลูกเต๋าหลายลูก หรือโยนเหรียญ

สร้างรหัสผ่านปลอดภัย

เปิดเครื่องมือ →

สุ่มรหัสผ่านแข็งแรง หรือ Passphrase (วลี) ที่จำง่ายกว่า

  1. เลื่อน ความยาว (4–64) และเปิด/ปิดชนิดตัวอักษร: พิมพ์ใหญ่/เล็ก/ตัวเลข/สัญลักษณ์
  2. เปิด "เลี่ยงตัวกำกวม" เพื่อตัด 0 O 1 l I ออก (อ่านง่ายขึ้น)
  3. ดู ตัววัดความแข็งแรง → กด คัดลอก หรือ "สุ่มใหม่"
รหัสสุ่มในเครื่องคุณ ไม่ถูกส่งหรือบันทึกที่ใด

อายุ / นับวัน / แปลง พ.ศ.↔ค.ศ.

เปิดเครื่องมือ →

เครื่องมือเกี่ยวกับวันที่ 4 แบบ

  1. อายุ: ใส่วันเกิด → ได้อายุ ปี/เดือน/วัน + อีกกี่วันถึงวันเกิดถัดไป
  2. นับวัน: เลือก 2 วันที่ → ได้จำนวนวันระหว่างกลาง (แสดงสัปดาห์+วันด้วย)
  3. บวก/ลบวัน: ใส่วันที่ตั้งต้น + จำนวนวัน (บวกหรือลบ) → ได้วันที่ผลลัพธ์
  4. แปลงปี: พ.ศ. ↔ ค.ศ. (บวก/ลบ 543) พร้อมวันที่แบบไทย

ชุดเครื่องมือข้อความ

เปิดเครื่องมือ →

จัดการข้อความหลายอย่างในกล่องเดียว

  1. วาง/พิมพ์ข้อความในกล่องใหญ่ — ระบบ นับตัวอักษร/คำ/บรรทัด/ย่อหน้า ให้ทันที
  2. แปลงตัวพิมพ์: ใหญ่หมด/เล็กหมด/ขึ้นต้นประโยค/สลับ
  3. จัดระเบียบ: ลบบรรทัดซ้ำ/บรรทัดว่าง/ช่องว่างเกิน · เรียงบรรทัด ก-ฮ/A-Z/สุ่ม/กลับด้าน
  4. เลขไทย ↔ อารบิก และ ตรวจเลขบัตรประชาชน 13 หลัก (เช็ค check digit)
