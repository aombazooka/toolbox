# Toolbox

เว็บรวม **เครื่องมือออนไลน์ฟรี** ใช้ง่าย ไม่ต้องล็อกอิน — **เว็บ static ล้วน (HTML/CSS/JS)
ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล ไม่มีการอัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์** ทุกอย่างทำงานในเบราว์เซอร์

**เครื่องมือ (14):** สร้าง QR · QR สำเร็จรูป (WiFi/vCard/อีเมล/SMS/โทร) · QR พร้อมเพย์ ·
ลดขนาด/แปลงรูป · รูป→PDF/รวม/แยกหน้า/ดึงหน้า · คำนวณผ่อน/สินเชื่อ · ชุดคำนวณ (BMI/ส่วนลด/VAT/%/ทิป) ·
สุ่มรายชื่อ/วงล้อ/เลข/ลูกเต๋า · สร้างรหัสผ่าน · อายุ/นับวัน/พ.ศ.-ค.ศ. · แปลงหน่วย/อุณหภูมิ/สกุลเงิน ·
อ่านเงินเป็นบาทถ้วน · คำนวณภาษีเงินได้ · ชุดเครื่องมือข้อความ

## ใช้งาน / โฮสต์

เป็นไฟล์ static ล้วน จึงเปิด/โฮสต์ที่ไหนก็ได้:

- **GitHub Pages (ฟรี):** repo → Settings → Pages → Source: *Deploy from a branch* →
  Branch `master` / folder **`/ (root)`** → Save → เว็บออนไลน์ที่ `https://<user>.github.io/<repo>/`
- **เปิดในเครื่อง:** เปิด `index.html` ตรงๆ ก็ได้ (สกุลเงินต้องเปิดผ่านเว็บเซิร์ฟเวอร์ถึงจะดึงเรตได้ —
  ใช้ `python -m http.server` หรือ `php -S 127.0.0.1:8000` ในโฟลเดอร์นี้ แล้วเปิด `http://127.0.0.1:8000/`)

## โครงสร้างไฟล์

```
index.html          หน้า Hub (การ์ดเครื่องมือ + ค้นหา)
<tool>.html         หน้าเครื่องมือแต่ละตัว (qr, convert, pdf, ...)
assets/css          สไตล์ (ธีม light/dark)
assets/js           ตรรกะเครื่องมือ (ฝั่ง client) — 1 ไฟล์ต่อ 1 เครื่องมือ
assets/vendor       ไลบรารีในเครื่อง: qr-code-styling, pdf-lib, jszip
.nojekyll           บอก GitHub Pages ไม่ต้องรัน Jekyll
```

## แก้ไข / เพิ่มเครื่องมือ

หน้าเครื่องมือแต่ละไฟล์เป็น HTML ในตัวเอง (มีหัว/ท้ายเว็บอยู่ในไฟล์) แก้ได้ตรงๆ:

- แก้ตรรกะเครื่องมือ → แก้ไฟล์ใน `assets/js/<tool>.js`
- เพิ่มเครื่องมือใหม่ → สร้าง `<tool>.html` (ก็อปโครงจากไฟล์ที่มี) + `assets/js/<tool>.js` +
  เพิ่มการ์ดใน `index.html` และลิงก์ในเมนูของทุกหน้า

> เวอร์ชัน PHP+MySQL เดิม (มีบัญชี/ประวัติ/ย่อลิงก์) ยังอยู่ในประวัติ git — ดึงกลับได้ด้วย
> `git log` แล้ว `git checkout <commit> -- <ไฟล์>`

## หมายเหตุ

- **สกุลเงิน** ดึงอัตราสดจาก `frankfurter.dev` (ฟรี ไม่ต้องคีย์) เพื่ออ้างอิงเท่านั้น
- **QR พร้อมเพย์** สร้าง payload ตามมาตรฐาน EMVCo/PromptPay + CRC16 — ควรลองสแกนด้วยแอปธนาคารจริง
  ก่อนใช้รับเงินจริง
- **ภาษีเงินได้** เป็นการประมาณเบื้องต้นตามอัตราขั้นบันไดปัจจุบัน — ตรวจสอบกับกรมสรรพากรก่อนยื่นจริง
